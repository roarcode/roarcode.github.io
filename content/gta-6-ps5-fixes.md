# GTA 6 PS5 Fixes: 9 Steps When It Won't Start or Load

> - **Quick answer:** GTA 6 PS5 fixes start here: **restart the PS5, then delete and re-download only if it still fails.** PlayStation's own list has 9 steps, fastest first.
> - **Safe and slow:** Safe Mode > **Clear Cache and Rebuild Database** > **Rebuild Database** does not delete your games, apps or saved data.
> - **Not a bug:** Rockstar targets **30 frames per second** on every console, so 30 fps is by design (Game Informer).

**Words used on this page.** *Safe Mode* is a special start-up menu for fixing problems. *Database* is the list of what is on your console. *fps* means frames per second: how many pictures the game draws each second.

> **19 Nov, 06:40 CET:** [PlayStation's status page](https://status.playstation.com) showed a PSN problem with launching games in Europe and the Americas. At our **07:09 CET** check that alert had cleared. If you still see "Your license is being verified" (players reported this, [@SJCFutures on X](https://x.com/SJCFutures/status/2123282165203185685)), wait and try again later. Do **not** delete the game. More in [GTA 6 not working](/glitches/gta-6-not-working/).

## The 9 steps (from PlayStation support)

1. **Check the PlayStation status page.** Open [status.playstation.com](https://status.playstation.com). If you see an alert, wait.
2. **Restart the PS5.** Press the **PS button**, select **Power**, then **Restart PS5**.
3. **Check the unlock time.** The game stays locked until midnight local time on 19 Nov 2026. See [is GTA 6 out](/launch-hub/is-gta-6-out/).
4. **Move the game off USB storage.** If GTA VI is on USB extended storage, move it to the PS5's internal storage.
5. **Turn on Console Sharing and Offline Play** if someone else's account owns the game. Go to **Settings > Users and Accounts > Other > Console Sharing and Offline Play**, then select **Enable**.
6. **Restore licenses.** On PS5 this is under **Settings > Users and Accounts > Other > Restore Licenses** (general PS5 menu path, check on your console).
7. **Update the system software.** Go to **Settings > System > System Software > System Software Update and Settings**.
   - **Required for GTA 6:** PlayStation says a PS5 system update must be installed before you play. See [GTA 6 PS5 update required (14.23.00): how to install](/glitches/gta-6-ps5-system-update-required/).
8. **Delete and re-download.** In **Game Library**, highlight GTA VI, press the **Options button**, select **Delete**. Then download it again. A network cable is better than Wi-Fi.
9. **Rebuild the database in Safe Mode.** Steps below.

## How to rebuild the database in Safe Mode

1. Hold the **power button** for 3 seconds to turn the PS5 off.
2. Press and hold the **power button** again. Let go after the **second beep**. The second beep comes about 7 seconds later.
3. Plug in the controller with a **USB cable**.
4. Press the **PS button** on the controller.
5. Select **6. Clear Cache and Rebuild Database**.
6. Select **Rebuild Database**.
7. Wait for it to finish, then start GTA VI.

> **Careful:** do **not** pick "Reset PS5" or "Reset PS5 (Reinstall System Software)". Those delete user data (PlayStation support).

## Error CE-108255-1: the game crashed

**What it means:** PlayStation's CE-108255-1 page says: "An error occurred with the game/application. Try updating your game." ([PlayStation: How to fix CE-108255-1](https://www.playstation.com/en-gb/support/error-codes/ps5/ce-108255-1/)) In plain words: something went wrong in the game and it closed.

**Reports, not confirmed by Rockstar:** some players on Reddit say they got this code in GTA VI soon after the Europe unlock on 19 Nov ([one Reddit report](https://www.reddit.com/r/GTA6/comments/1xztwwk/ps5_error_ce1082551_in_gta_vi_tried_almost/)). Rockstar and PlayStation have not posted about it for GTA VI.

**What the error-code page gives:** only one step, **update the game**. In **Game Library**, highlight GTA VI, press the **Options button**, select **Check for Update** ([PlayStation: How to fix CE-108255-1](https://www.playstation.com/en-gb/support/error-codes/ps5/ce-108255-1/)). The page then points to PlayStation Repairs for more help.

**If it keeps crashing:** the other steps are general PlayStation troubleshooting, not from the error-code page. We list them in the order PlayStation's crash guide gives them, with the Rebuild Database step from its launch-issues guide, each with its own source.

1. **Update the PS5.** Make sure the system software is the latest version. Go to **Settings > System > System Software > System Software Update and Settings** ([PlayStation: game freezes or crashes](https://www.playstation.com/en-us/support/games/game-freeze-crash/), menu path from [PlayStation: game launch issues](https://www.playstation.com/en-us/support/games/game-launch-issues/)).
2. **Delete and reinstall GTA VI.** Highlight it, press the **Options button**, select **Delete**, then download it again. Deleting and reinstalling is one of PlayStation's crash fixes ([PlayStation: game freezes or crashes](https://www.playstation.com/en-us/support/games/game-freeze-crash/)). The game is big, so the download can take a long time: PlayStation says to keep at least 212 GB free ([PlayStation: GTA VI page](https://www.playstation.com/en-us/games/grand-theft-auto-vi/); more in our [pre-load size guide](/launch-hub/preload-size/)).
3. **Rebuild the database.** Start the PS5 in Safe Mode, then select **Clear Cache and Rebuild Database > Rebuild Database**. Steps above ([PlayStation: game launch issues](https://www.playstation.com/en-us/support/games/game-launch-issues/), [PlayStation: Safe Mode](https://www.playstation.com/en-us/support/hardware/safe-mode-playstation/)).
4. **Last try: reset the PS5.** Back up your saves first, because a reset **erases all data** on the console storage. Go to **System > System Software > Reset Options > Reset Your Console**, then install the game again ([PlayStation: game freezes or crashes](https://www.playstation.com/en-us/support/games/game-freeze-crash/)).

If it still crashes, contact [Rockstar Support](https://support.rockstargames.com/) about the game.

## FAQ

### What is error CE-108255-1 in GTA 6?
PlayStation's CE-108255-1 page says an error occurred with the game and tells you to try updating the game. That is the only step on that page. PlayStation's general crash and launch guides then list updating the PS5, deleting and reinstalling the game, rebuilding the database in Safe Mode and, as a last resort, a reset. Steps above, each with its own source.

### Why won't GTA 6 start on my PS5?
It may be locked (before midnight local time on 19 Nov), still downloading, on the wrong account or hit by a service problem. Work through the 9 steps.

### Does rebuilding the database delete my games?
No. PlayStation says Rebuild Database scans the drive and builds a new list of content. It does not erase data.

### Is there a 60 fps mode on PS5?
Not announced. Rockstar says it targets 30 fps on all consoles. PS5 Pro adds sharper image and ray-traced shadows (PlayStation Blog, Game Informer).
