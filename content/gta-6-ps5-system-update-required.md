# GTA 6 PS5 Update Required (14.23.00): How to Install

> - **Quick answer:** PlayStation Support says a PS5 system software update is **required before playing GTA VI**. Install it before midnight on 19 Nov. The current version on PlayStation's update page is **26.07-14.23.00**.
> - **Do this:** Settings > System > System Software > System Software Update and Settings > Update System Software. It is about 1.3 GB (Push Square).
> - **Watch out:** pre-loading the game does not install this update. Sony normally gives a grace period, but press reports say there is none this time.

**Words used on this page.** *System software* is the PS5's own operating system, like the "brain" of the console. *Firmware* is another name for it. A *version number* like 26.07-14.23.00 tells you which update you have. *Safe Mode* is a special start-up menu for fixing problems. *USB drive* is a small stick you plug in to carry files.

## What PlayStation actually said

- On 17 Nov at 8:25 pm ET (02:25 CET on 18 Nov), the official PlayStation Support US account posted: "Sony Interactive has issued a PS5 system software update that is required before playing Grand Theft Auto VI. Players should download this update prior to midnight on November 19..." ([post](https://x.com/PS_Support_US/status/2122863683881619685))
- PlayStation's own update page lists **26.07-14.23.00** as the newest version. Its only note is "We've made some security fixes to the system software." ([PlayStation update list](https://www.playstation.com/en-us/support/hardware/ps5/system-software-info/))
- The support post does not print the version number. News sites (Push Square, tbreak) match the post to 26.07-14.23.00. So: **install the newest version your PS5 offers. Today that is 26.07-14.23.00.**
- If a newer version appears later, install that one. We will update this page.

## Step 1: Check which version you have

1. Press the **PS button** on your controller to open the control center. Or go to the home screen.
2. Go to **Settings** (the gear icon at the top right of the home screen).
3. Select **System**.
4. Select **System Software**.
5. Select **Console Information**. PlayStation's guide uses this screen for console details.
6. Look for the system software version. If it says **26.07-14.23.00** (or something newer), you are done.

## Step 2: Install the update over the internet

1. From the home screen, select **Settings**.
2. Select **System**.
3. Select **System Software**.
4. Select **System Software Update and Settings**. If a new version is ready, you will see **Update Available**.
5. Select **Update System Software**.
6. If the console asks how, pick **Update Using Internet** (a choice shown in outlet guides, not on PlayStation's page).
7. Wait for the download. Your PS5 will restart. Do not turn it off while it installs.

![PS5 System Software Update and Settings screen with Update System Software highlighted](TODO: image:gta-6-ps5-system-update-required-step-2 — menu screen, PS5: Settings > System > System Software > System Software Update and Settings, Update System Software highlighted)
*Caption: Menu screen. Select Update System Software.*

**Tip: turn on automatic updates so you never miss one.** On the same screen, turn on **Download Update Files Automatically** and **Install Update Files Automatically**. Then go to **Settings > System > Power Saving > Features Available in Rest Mode** and turn on **Stay Connected to the Internet**. (PlayStation's GTA VI support page lists these steps.)

## Step 3: If the update is stuck or fails

1. Press the **PS button** on your controller to open the control center.
2. Select **Downloads/Uploads**.
3. Highlight the system software update.
4. Select **View Error Info**, then **Try Again**.
5. If it fails again and again, use the USB method below.

PlayStation also says: do not turn off the console during the install, and do not install right before or after a power cut. Use only the update file from PlayStation, never one from another site. ([PlayStation: how to update system software](https://www.playstation.com/en-us/support/hardware/ps5/system-software/))

## Step 4: Update with a USB drive (only if Step 2 and 3 fail)

You need a PC or Mac, a USB drive formatted as **FAT32 or exFAT**, and about **1.1 GB** of free space on it.

1. Turn off your PS5.
2. On your computer, create a folder named **PS5** on the USB drive.
3. Inside it, create a folder named **UPDATE**. Use capital letters.
4. Download the **PS5 console update file** from [PlayStation's official page](https://www.playstation.com/en-us/support/hardware/ps5/system-software/).
5. Save it in the UPDATE folder. Name it exactly **PS5UPDATE.PUP**.
6. Plug the USB drive into your PS5.
7. Start in **Safe Mode**: press and hold the **power button** and let go after the **second beep**.
8. Connect your controller with a USB cable if it does not respond.
9. Select **Update System Software** (outlet guides call this option 3).
10. Select **Update from USB Storage Device**, then **OK**.

If the PS5 does not see the file, check the folder and file names. They must be in capital letters.

> **Careful:** do **not** choose "Reset PS5 (Reinstall System Software)". PlayStation says reinstalling deletes all data on the console.
