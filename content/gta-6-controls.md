# GTA 6 Controls on PS5 and Xbox: Default Layout and Haptics

> - **Quick answer:** The **default button layout is not confirmed yet.** We will add each button after we see it on a PS5 or Xbox screen.
> - **Confirmed:** on PS5 and PS5 Pro, high-fidelity **haptic feedback** is built for the DualSense controller and can be adjusted in accessibility settings.
> - **Do not trust one-off posts** about buttons. We only add a button after we see it on a PS5 or Xbox screen ourselves.

**Words used on this page.** *Controls* are the buttons you press to move and act. *Haptics* means small vibrations you feel in the controller. *Layout* is which button does which job. *DualSense* is the PS5 controller.

## What is confirmed

- PS5 and PS5 Pro: "high-fidelity haptic feedback" fully built for DualSense and adjustable via accessibility settings (Rockstar, via Game Informer).
- Xbox button layout: **not announced**.
- PS5 button layout: **not announced**.
