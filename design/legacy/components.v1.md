# Components — copy-paste for Eleventy

Convention: **BEM**. `.block`, `.block__element`, `.block--modifier`. Category theming = helper class `.cat-missions | .cat-money | .cat-collectibles | .cat-vehicles | .cat-weapons | .cat-glitches | .cat-beginner | .cat-ps5` on any element (sets `--accent`). Don't rename classes; Lead Engineer mirrors them exactly.

**All CSS lives in `components.css`** (needs `fonts.css` + `tokens.css` first, plus `ui.js` deferred for menu/search/ToC/map-filter behaviour). The live markup of every snippet below is in `mockup-home.html`, `mockup-guide.html`, `mockup-hub.html`, `mockup-search.html` (generated by `src/build_pages.py`). Section numbers = `components.css` headings.
Every page must include the **disclaimer bar** (top) and **footer disclaimer**: *Unofficial fan site — not affiliated with Rockstar Games*.

```html

<span class="badge badge--rumour"><svg>alert</svg>Unverified</span>                 <!-- rumour: dashed amber -->
```

Rule: rumours/leaks/single-source claims → `badge--rumour` next to the claim and in the page header; official or reputable-preview facts → `badge--official` with a link in the source block. Icons are inline 24-px stroke SVGs (`aria-hidden`), text is always present.

## 14. Per-guide OG image
`og/og-template.svg` (single `<text>` node containing the literal `{{title}}`, plus `{{category}}`) or `og/og-template-2line.svg` (`{{title_line1}}`, `{{title_line2}}`). Disclaimer + wordmark + background are baked in. Render with `src/render_og.mjs` (`renderOg({title, category})` → PNG buffer, auto-wraps: ≤22 chars 1 line, else 2 lines ≤28 chars each with ellipsis). Fonts for resvg: `fonts/Syne-ExtraBold-static.ttf`, `fonts/Inter-SemiBold-static.ttf` (`loadSystemFonts:false`).
