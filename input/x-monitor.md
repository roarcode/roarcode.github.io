## 4. Data limits

- **25 X calls used** (the cap for this task). That is why some outlet timelines (Polygon, Game Informer, Xbox, The Game Awards) were looked up for follower counts but not fully crawled for posts.
- **No likes/reposts filter.** `min_likes:` / `min_reposts:` are stripped by this X search API (“X's search API has no engagement filter”). `sort_order=relevancy` often returned near-zero-engagement posts and brand-new fan accounts, not viral posts. High-engagement examples therefore come mainly from `from:` searches and `get_users_posts` on known official, outlet and fan-news accounts. **Community-wide ranking is incomplete:** a viral post from an account we did not already know to query could have been missed.
- **Trends:** Worldwide trends at this minute did not list GTA VI (the list was dominated by other regions’ entertainment topics). New Zealand trends did include `#GTA6`, `GTA VI`, `Rockstar`, `Grand Theft Auto VI`, `GOTY`, `Vice City`, `PlayStation` and `Lucia`. The trends tool did **not** return `tweet_count` even when that field was requested, so we cannot rank those trends by volume.
- **News clusters are not post URLs.** `search_news` returned 20 story clusters (for example single-player-only-at-launch, install-size talk, day-off-work, preview-detail debates, and several rumor/leak clusters). Those URLs are `x.com/i/trending/...` pages, not embeddable posts, so they were used only as context — never as example post links.
- **@RockstarSupport:** zero posts returned for 11–18 Nov, both as a user timeline (excluding replies/reposts) and in a keyword search. There is no official known-issue or outage post to cite yet.
- **Sony firmware confirmation:** IGN says Sony confirmed firmware 14.23 in a social post boosted by Rockstar. That original Sony/@PlayStation post was not in the @PlayStation search results retrieved here.
- **Reviews are minutes old.** IGN/GameSpot/Eurogamer/Kotaku review posts went up around 12:00–12:08 CET. Counts will change quickly. Numeric review scores were **not** in the post text we retrieved; do not invent scores — open the linked reviews before stating them.
- **Early-player discoveries are too fresh to rank.** Recency search from 11:00 UTC (12:00 CET) onwards found many “already playing / the trick works” posts, almost all with 0 likes and low views because they were 0–10 minutes old. Secrets, money methods, glitches and cars were also searched; this run did not surface reliably engaged, proof-backed finds. Recheck after a few hours.
- **Leaks and datamines:** News clusters mentioned leak clips and rumoured scope figures, but this run did not retrieve high-engagement public *posts* we could cite. No piracy or file links were collected.
- **Language bias:** Most queries used `lang:en`. The highest-engagement region-change warning we found is in Arabic (@MrMrKlNG); a strictly English search would have missed it.
- **Sample size:** Topical searches returned 23–25 posts each; official/fan timelines returned 3 (Rockstar Games), 0 (Rockstar Support), 13 (GTASeries), 20 (IGN, GameSpot, Kotaku), and 2 (PlayStation, in a filtered search). This is a snapshot, not a complete census of the last 48 hours.
